# GitHub Security Assessment

**منصة تقييم الضوابط الأمنية لمستودعات GitHub وتتبع المعالجة**

مستودع المشروع الجامعي لدراسة وبناء منصة لتقييم ضوابط أمنية محددة في مستودعات GitHub، وتوثيق الأدلة، ومتابعة المعالجة وإعادة التحقق.

## الحالة الحالية

تتوفر وثائق السمينار الأول والتقرير المرحلي، وتعرض نطاق المشروع وتصميمه والدراسات المرجعية ونتائج نموذج محلي محدود. المنصة الإنتاجية والتحقق الحي على GitHub ما زالا ضمن العمل القادم. يحتوي المستودع أيضًا على مذكرات المراجعة العربية التي أُعدّت أثناء الدراسة.

## السمينار الأول والتقرير المرحلي

النسخ المراجعة بتاريخ 28 أكتوبر 2026:

| التقرير المرحلي الأول | [PDF](docs/seminar-1/GitHub_Security_Report_Part1.pdf) | [Word](docs/seminar-1/GitHub_Security_Report_Part1.docx) |

تتضمن ملاحظات PowerPoint شرحًا عربيًا أوسع للدراسات وللنقاط المعروضة. التقرير مكتوب بالإنجليزية، ويتضمن المعمارية ومسار التقييم ومخطط Gantt والمراجع.

## المواد البحثية

راجع [فهرس الدراسات ومذكرات المراجعة](docs/research/README.md). تتوافر المذكرات بصيغتي PDF وHTML، وتضم روابط المصادر الأصلية وحدود النتائج والأمثلة التعليمية.

نشتق المتطلبات والتصميم من فهم المشكلة والمقارنة بالأعمال السابقة، ونميّز في الوثائق بين المقترح والمنفذ والمتحقق منه.
