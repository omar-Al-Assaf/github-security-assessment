# GitHub Security Assessment

**منصة تقييم الضوابط الأمنية لمستودعات GitHub وتتبع المعالجة**

مستودع المشروع الجامعي لدراسة وبناء منصة لتقييم ضوابط أمنية محددة في مستودعات GitHub، وتوثيق الأدلة، ومتابعة المعالجة وإعادة التحقق.

## الحالة الحالية

المشروع في مرحلة دراسة المجال والأعمال السابقة وتحديد النطاق. يحتوي المستودع حاليًا على التعريف الأولي ومذكرات المراجعة العربية التي أُعدّت أثناء الدراسة. الوظائف المذكورة أعلاه تصور مقترح للمشروع، ويحتاج تنفيذها وتقييم فائدتها إلى عمل لاحق.

## المواد البحثية

راجع [فهرس الدراسات ومذكرات المراجعة](docs/research/README.md). تتوافر المذكرات بصيغتي PDF وHTML، وتضم روابط المصادر الأصلية وحدود النتائج والأمثلة التعليمية.

سنشتق المتطلبات والتصميم من فهم المشكلة والمقارنة بالأعمال السابقة، ونميّز في الوثائق بين المقترح والمنفذ والمتحقق منه.
