# مراجعة أكاديمية للمخططات والتوثيق الحالي

المراجعة الأحدث للمحتوى والتصحيحات: [مراجعة 1 نوفمبر](DESIGN_CONTENT_REVIEW_2026-11-01.md). الفقرات التالية تسجل المراجعات المتتابعة؛ الحصر الجاري في [فهرس المخططات](diagrams/README.md).

التاريخ: 1 نوفمبر 2026. النطاق عند المراجعة الأولى: ملفات المخططات الستة، ومناظرها الثمانية، ووصف UC05 وUC07 وUC08، وحصر المتطلبات، وقالب التقرير المرفق. يتبعها أدناه تحديث الإجراءات المطبقة وإضافة UC02. هذه مراجعة إرشادية قائمة على المصادر، وليست شهادة مطابقة ISO أو إقرار قبول من المشرف. لا تشمل تدقيقًا جديدًا لجميع دراسات السمينار أو نتائج المقارنة البحثية.

## الحكم

الموجود مسودة تصميم منظمة تصلح للبناء عليها، لكنه ليس حزمة توثيق نهائية مكتملة أو مثبتة المطابقة لجميع متطلبات التسليم. تحسين الخط والتوزيع وحده لا يثبت الدقة الدلالية أو اكتمال المتطلبات. مرجع التسليم المحلي هو قالب الجامعة وتعليمات المشرف؛ المعايير التالية مراجع فنية مساندة، ولا نفترض أن الجامعة أوجبت تطبيقها كاملة.

## أولويات الاستكمال المقترحة

1. تدقيق ترميز علاقات Use Case وحراسات Activity، وتوحيد معرفات الحالات والأسماء بين النص والرسم.
2. استكمال أوصاف الحالات المتبقية ومصفوفة الصلاحيات، والتحقق من تغطية المتطلبات بدل استهداف عدد رسوم معين.
3. توثيق حدود المكونات والبيانات وعقودها وقرارات التصميم اللازمة للتنفيذ؛ إضافة Sequence وState وغيرهما حيث يعالجان غموضًا حقيقيًا.
4. تجهيز نسخة التقرير الرسمي الإنجليزية وفق القالب، مع ترقيم كل شكل وعنوانه وشرحه والإحالة إليه، وتوثيق مصادر الأشكال أو التكييف عند الاقتباس. هذا تنظيم موصى به للتسليم، وليس ادعاء بأن كل تفصيل منه مفروض بالنصوص التي راجعتها.
5. ربط المتطلبات بمعايير قبول ثم بنتائج تنفيذ واختبار فعلية عند البناء؛ لا نسمي المخططات أو الأهداف نتائج تجريبية.

هذه أولويات مراجعة وليست متطلبات جديدة وافق عليها المشرف. لم تغير جولة البحث الأولى الخط أو الرسومات، ولم تشغل اختبارات أو منصة فعلية.
