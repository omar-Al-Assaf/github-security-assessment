# قائمة العمل المؤقتة وسياسة Kanban

1 نوفمبر 2026. هذا الملف قائمة عمل يدوية وسياسة أولية، وليس دليلًا على تطبيق Kanban كامل. لم تنشأ لوحة GitHub Projects ضمن هذا العمل. التوصية للمتابعة اليومية هي لوحة مرتبطة بالمستودع وطلبات المراجعة، ويحتفظ هذا الملف بالقواعد بدل إنشاء سجل حالة ثانٍ عند الانتقال إليها.

## قواعد العمل

- وحدة العمل بند له مخرج واضح وشرط إنجاز ومرجع للدليل، مثل مصفوفة الصلاحيات أو مسار التهيئة.
- يبدأ البند عند سحبه من الجاهز إلى التنفيذ. ينتهي بعد استيفاء شرط إنجازه ومراجعته وتسجيل الدليل؛ إرسال مسودة للمراجعة ليس انتهاءً.
- **الحد الإجمالي WIP = 1**، ويشمل التنفيذ وانتظار المراجعة والتصحيح والتعثر بعد البدء. لا يقتصر على عمود «جارٍ».
- لا نسحب بندًا جديدًا عندما يشغل بند غير منتهٍ هذا الحد. نعالج سبب الانتظار أو نصغر البند قبل زيادة العمل.
- لا يوصف بند بأنه جاهز ما دامت مدخلاته اللازمة غير متاحة. الانتظار قبل بدء البند يختلف عن تعثره بعد البدء؛ الثاني يبقى ضمن WIP.
- قبول بند مراجعة توثيق لا يعني تنفيذ المنصة. وفي البنود التي يشترط إنجازها دمج PR، لا يكفي فتحه أو إغلاقه دون دمج.

**WIP الحالي = 1: AC-01.** لا نعتبره صفرًا لمجرد أن البند ينتظر المراجعة. الفحوص الـ24 باقية ضمن نطاق GitHub، وAWS يأتي بعد إكماله إذا بقي وقت.

## ما ينقص المتابعة

يجب تسجيل بدء كل بند ونهايته وانتقالاته، ومتابعة WIP والعدد المنجز وعمر البنود غير المنتهية وزمن إنجاز البند. لم تسجل أوقات العمل السابق بما يكفي لحساب هذه المقاييس؛ لا نستنتجها من تواريخ Commits.

لم نحدد بعد توقعًا زمنيًا للخدمة SLE مع احتماله. يثبت كتوقع أولي معلن ثم يراجع بالبيانات، ولا يقدم بوصفه قياس أداء سابقًا أو وعد تسليم.

النقل إلى GitHub Projects وحده لا يكمل المنهجية. يلزم تعريف الحالات والشروط والتسجيل ومراجعة البنود المنتظرة بانتظام. تؤتمت الأحداث التي يمكن إثباتها، مثل انتقال بند مرتبط عند دمج PR إذا كان ذلك شرط إنجازه؛ يبقى تقدير الجاهزية وقبول المحتوى قرارًا بشريًا.

المراجع: [The Kanban Guide، مايو 2025](https://kanbanguides.org/the-kanban-guide/2025.5/) لتعريف سير العمل وWIP والمقاييس، و[توثيق GitHub Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/automating-your-project/using-the-built-in-automations) للأتمتة المدمجة. هذه توصية لإدارة مشروعنا؛ لا تعني أن الأتمتة أُعدت بالفعل.
