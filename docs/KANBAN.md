# لوحة العمل

1 نوفمبر 2026. متابعة يدوية داخل مستودع المشروع. الحد: **بند واحد جارٍ في الوقت نفسه**. نقل بند إلى «للمراجعة» يعني توفر مخرج يمكن مراجعته، ولا يعني تنفيذ منصة أو نجاح اختبار حي.

| البند | الحالة | المخرج أو شرط الانتقال |
|---|---|---|
| AC-01 — صلاحيات الأدوار وسحب الوصول | للمراجعة | [المصفوفة](ACCESS_CONTROL_MATRIX.md)، ومواءمة الأوصاف والرسوم؛ الاقتراح يتيح للمسؤول التشغيل والاطلاع أيضًا |
| AUTH-01 — الدخول وتهيئة المؤسسة والمسؤول الأول والاسترداد | جاهز | وصف مسار واحد واضح، وتحديد ما يحتاج كلمة مرور وموضع التهشير وحماية الجلسة |
| ARCH-01 — المكونات وعقود التواصل | جاهز بعد AUTH-01 | Component Diagram يستند إلى الصلاحيات والتهيئة وحدود Web وWorker |
| DATA-01 — نموذج البيانات وERD | جاهز بعد ARCH-01 | المؤسسات والعضويات والمهام والأدلة والنتائج وتاريخها وعلاقاتها |
| FLOW-01 — تسلسل أول تقييم وحالات المهمة | جاهز بعد DATA-01 | Sequence وState للمسار الأول، بما فيه الانقطاع والإلغاء والإقرار النهائي |
| GH-01 — عقد الوصول إلى GitHub App للمحطة الأولى | جاهز | الصلاحيات وendpoints ونتائج التحقق المصرح به؛ يبدأ قبل ادعاء صحة الجمع أو المحرك على GitHub |
| DESIGN-01 — توثيق الحالات ومراجعة الحزمة | أُنجزت المراجعة | [تقرير المراجعة](DESIGN_CONTENT_REVIEW_2026-11-01.md)؛ التوثيق مرفوع في طلب مراجعة، وبقية التصميم مذكورة فيه |

لا يوجد بند جارٍ بعد تسليم مسودة AC-01 للمراجعة. نسحب البند التالي عندما تتضح مدخلاته، ونحدث هذه اللوحة مع العمل. الفحوص الـ24 تبقى ضمن نطاق GitHub المعتمد، وAWS يأتي بعد إكمال ذلك النطاق إذا بقي وقت.
