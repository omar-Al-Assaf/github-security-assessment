## ما الذي يراجعه المستخدم؟

| المستوى | المعلومات المطلوبة |
|---|---|
| التقييم | المستودعات والنطاق والفحوص المختارة، ونسخة السياسة، وحالة التنفيذ وأوقاته وحدود الاكتمال |
| السؤال | المطلوب والمقروء والحكم والسبب، مع تمييز دعم الفحص وانطباقه وعدم الحسم |
| الدليل | القيم المحفوظة اللازمة للحكم، ومصدرها ونافذة جمعها واكتمالها ومراجعها، مع حجب البيانات الحساسة |
| التاريخ | التقييمات والظهور السابق للمخالفة ونسخ المتطلبات وروابط الأدلة؛ تبقى كل نتيجة مرتبطة بزمنها |
| المقارنة | فروق المتطلبات والنطاق والقيم والأحكام، وقابلية المقارنة لكل سؤال وسبب تعذرها عند وجوده |

## المسار الأساسي — مراجعة تقييم ودليله

1. يختار المستخدم مؤسسته ثم تقييمًا من التاريخ المحفوظ. تتحقق المنصة من الجلسة والعضوية وصلاحية الاطلاع على التقييم والنطاق المطلوبين.
2. تسترجع المنصة المحتوى المحفوظ وتعرض نطاق التقييم ونسخة السياسة وحالة التنفيذ والنتائج المتاحة. تبين الفحوص المختارة من الكتالوج المعتمد ذي الفحوص الـ24؛ لا توحي بأن الفحوص خارج نطاق التشغيل قد قُيّمت.
3. يختار المستخدم سؤالًا لمراجعة نتيجته. تعرض المنصة المتطلب وقيمه المطلوبة والقيم المقروءة والحكم وتفسيره، وتفصل بين عدم الحسم وعدم الانطباق وعدم الدعم وبين استيفاء المتطلب.
4. يطلب المستخدم الدليل المرتبط بالنتيجة. تعيد المنصة التحقق من صلاحية الوصول إلى الدليل نفسه، ثم تعرض بياناته المحفوظة ومصدرها وأوقاتها وحدودها دون كشف أسرار الاتصال. لا تعتمد على فحص صلاحية الصفحة السابقة وحده.
5. يستطيع المستخدم الانتقال إلى التقييمات والظهور السابق المرتبطين بالنطاق أو المخالفة، ضمن صلاحياته. تعرض الروابط إلى السجلات الأصلية؛ لا يستبدل التاريخ بأحدث نتيجة.
6. تنتهي المراجعة دون تعديل نتائج الفحص أو حالة المخالفة. متابعة المعالجة وظيفة UC06، وإنتاج التقرير وظيفة UC10.

## مسار اختياري — مقارنة تقييمين

1. يختار المستخدم تقييمًا ثانيًا محفوظًا من مؤسسته. تتحقق المنصة من حق الاطلاع على التقييمين وكل المراجع الداخلة في المقارنة.
2. تطابق الأسئلة وفق معرف المستودع الثابت، والفحص ودلالته، والنطاق والموضوع عند وجوده. تبين العناصر المشتركة والمضافة والخارجة من النطاق دون اعتبار غياب عنصر دليلًا على إصلاحه.
3. تتحقق لكل سؤال من تكافؤ المتطلب والنطاق ودلالة المقيّم، وتعرض فروق القيم المطلوبة والقراءات والأحكام ومراجع الأدلة. اختلاف رقم نسخة السياسة وحده لا يمنع المقارنة إذا بقي المتطلب المعني مكافئًا؛ وتساوي معرف الفحص وحده لا يكفي إذا تغير معنى السؤال.
4. تعرض نتائج المقارنة وحدودها، بما فيها البيانات الناقصة واختلاف زمن الجمع. قد تكون بعض الأسئلة قابلة للمقارنة وبعضها غير قابل؛ لا يحول اختلاف جزء واحد المقارنة كلها إلى حكم موحد.
5. تميز المنصة اختلاف الإعداد المقروء عن اختلاف السؤال المطلوب أو نطاقه. مراجعة الفروق لا تعيد حساب التاريخ بسياسة جديدة ولا تعيد تصنيف المخالفات؛ تأكيد زوالها وتحديثها يتبع UC08.

## البدائل والاستثناءات

| الرمز | الحالة | السلوك المطلوب |
|---|---|---|
| A1 | طلب غير مخول أو مرجع لتقييم أو دليل يخص مؤسسة أخرى | رفض الوصول دون كشف محتوى المرجع؛ ينطبق ذلك على كل طلب تفاصيل أو دليل أو مقارنة |
| A2 | تنفيذ فاشل أو جارٍ دون نتائج نهائية متاحة | عرض الحالة والمخرجات المحفوظة المتاحة فقط؛ لا ينشئ نجاحات أو نتائج افتراضية |
| A3 | تقييم جزئي أو سؤال غير محسوم | إظهار ما ثبت وما تعذر وسبب التعذر، دون إخفاء القيود أو اعتبار غياب المخالفة نجاحًا |
| A4 | دليل غير متاح أو مرجع لا يمكن استرجاعه | توضيح التعذر؛ لا تستبدل الدليل التاريخي بقراءة GitHub حالية وتقدمها بوصفها الدليل الأصلي |
| A5 | بيانات محفوظة قديمة أو اتصال مفصول | عرض زمن الدليل وحدوده؛ الاطلاع المصرح على التاريخ لا يعني إثبات الوضع الحالي أو جاهزية الاتصال |
| A6 | متطلبات أو نطاق أو دلالة فحص مختلفة بين التقييمين | عرض الفروق وتحديد الأسئلة غير المتكافئة، دون تسمية اختلاف النتيجة إصلاحًا تلقائيًا |
| A7 | سؤال موجود في تقييم واحد فقط أو بياناته غير كافية في أحدهما | بيان الخروج أو الإضافة أو تعذر الحسم؛ لا يستنتج زوال المخالفة من غيابها عن العرض |
| A8 | تعذر استرجاع البيانات المحفوظة | عرض خطأ مفهوم دون تغيير السجلات أو الادعاء بعدم وجود تقييمات أو مخالفات |

## قواعد التفسير

- الدليل يثبت ما جمع في نافذته الزمنية وبحدوده؛ عرض التاريخ لا ينفذ تقييمًا جديدًا ولا يختبر push أو merge على GitHub.
- تعرض حالة التنفيذ مستقلة عن الحكم الأمني، وحالة متابعة المعالجة مستقلة عن نتيجة التحقق. نجاح المهمة لا يعني استيفاء جميع المتطلبات، والإغلاق الإداري لا يثبت الإصلاح.
- تظهر القيم والمراجع اللازمة للمراجعة؛ لا يفرض هذا السيناريو عرض استجابة API كاملة أو كشف رموز الاتصال أو أسرار المشروع.
- اختلاف القيم المقروءة قد يشير إلى تغير إعداد، لكن تغيير السياسة وحده لا يثبت إصلاحه. تبقى نسبة التغير إلى سببه مقيدة بالأدلة المتاحة.
- هذا مسار اطلاع ومقارنة. تغيير السياسة أو متابعة المخالفة أو طلب إعادة التحقق يحتاج صلاحية الحالة المعنية وطلبًا مستقلًا؛ دور المراجع لا يمنح هذه الصلاحيات بمجرد عرض النتائج.
