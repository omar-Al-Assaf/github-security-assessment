# UC10 — عرض التقارير وطباعتها

الحالة: تصميم مستهدف. التاريخ: 1 نوفمبر 2026.

| العنصر | الوصف |
|---|---|
| الهدف | إعداد تقرير قابل للمراجعة والطباعة من تقييمات محفوظة، مع إظهار نطاقه وأحكامه وأدلته وحدوده |
| الأطراف الرئيسية | المراجع والمقيّم المخولان داخل المؤسسة |
| المحفز | اختيار «عرض التقرير» من تقييم محفوظ، ثم اختيار الطباعة عند الحاجة |
| المدخلات | المؤسسة ومرجع التقييم، ومرجع التقييم الثاني عند تضمين مقارنة، ومراجع الخطط والأدلة المرتبطة عند وجودها |
| الشروط السابقة | جلسة وعضوية وصلاحية اطلاع على التقييم وكل البيانات المدرجة في التقرير |
| النتيجة الناجحة | معاينة تقرير مرتبطة بمراجعها، مع نسخة قابلة للطباعة من المتصفح |
| ضمان الفشل | لا يكشف بيانات غير مخولة أو أسرارًا، ولا يعرض تقريرًا مكتملًا إذا تعذر تجهيز بياناته دون بيان، ولا يغير التقييمات أو المخالفات |

## محتوى التقرير

| القسم | المحتوى المطلوب |
|---|---|
| التعريف والنطاق | المؤسسة، ومراجع التقييمات، والمستودعات والفروع أو النطاقات المعنية، والفحوص المشمولة، ونسخة السياسة، ووقت إعداد التقرير |
| حالة التنفيذ والتغطية | اكتمال التشغيل أو جزئيته أو فشله، والفحوص التي قُيّمت وما تعذر أو لم ينطبق أو لم يكن مدعومًا، وحدود البيانات |
| النتائج | السؤال والمتطلب والقيمة المطلوبة والقراءة والحكم والسبب، دون اختزالها في درجة أمان شاملة |
| الأدلة | القيم اللازمة للمراجعة ومراجع الأدلة ومصادرها ونافذة جمعها وحدودها، بعد حجب البيانات الحساسة |
| المخالفات والمتابعة | المخالفات المرتبطة بنتائج التقييم، مع تمييز حالة المتابعة الإدارية ووقت تحديثها عن الحكم الأمني ودليله |
| الخطط عند وجودها | التعديل المقترح وأسبابه وأثره المتوقع وحدود النموذج ومراجع مدخلاته؛ يبين هل توجد إعادة تحقق مرتبطة به وما نتيجتها |
| المقارنة عند طلبها | فروق التقييمين وتكافؤ الأسئلة والمتطلبات والنطاق، وحدود المقارنة وفق UC09 |

الطباعة تحافظ على المعلومات الأساسية ومراجعها في النص؛ لا تكتفي بروابط لا يمكن للقارئ فهم الحكم دون فتحها. تبقى الروابط وسيلة للوصول إلى التفاصيل المحفوظة داخل المنصة وفق صلاحياتها.

## المسار الأساسي

1. يختار المستخدم مؤسسته وتقييمًا محفوظًا، ثم يطلب عرض تقريره. إذا طلب تضمين مقارنة أو خطة، يحدد المراجع المرتبطة التي يحق له الاطلاع عليها.
2. تتحقق المنصة من صلاحية الوصول إلى جميع التقييمات والمستودعات والأدلة والخطط المطلوبة وانتمائها إلى المؤسسة. لا تعتمد على صلاحية فتح الصفحة السابقة وحدها.
3. تسترجع المحتوى المحفوظ وتثبت مراجع التقييمات ونسخ السياسات وأوقات الأدلة. عند إدراج متابعة إدارية أحدث، تبين وقتها وتفصلها عن حالة الإعداد وقت جمع الدليل.
4. تجهز أقسام التقرير من النتائج المتاحة، وتظهر الجزئية أو عدم الحسم وأسبابهما صراحة. تدرج المقارنة وفق قواعد UC09 والخطة بحدودها عند طلبهما، وتحجب الأسرار والحقول الحساسة.
5. تعرض معاينة التقرير ووقت إعدادها ومراجعها. تظل الفحوص خارج نطاق التقييم ظاهرة بوصفها خارج تغطيته؛ لا يوحي تقرير جزء من الكتالوج بأن الفحوص الـ24 كلها قُيّمت.
6. إذا اختار المستخدم الطباعة، تعرض المنصة نسخة معدة للطباعة تطابق محتوى المعاينة ومراجعها. لا تستبدل التقييم المختار بأحدث تقييم أو تغير بيانات المتابعة بصمت عند الانتقال إلى الطباعة.
7. يفتح المتصفح حوار الطباعة، ويختار المستخدم وجهة الإخراج ويؤكد العملية أو يلغيها. إتاحة النسخة أو فتح الحوار لا يثبت أن ورقة طُبعت فعليًا.
8. تنتهي العملية دون تغيير نتائج التقييم أو حالة المخالفات أو تشغيل تقييم جديد. يسجل طلب إعداد التقرير ومراجعه وفق متطلب التدقيق، ولا توصف العملية بأنها نجاح طباعة خارج ما يمكن رصده.

## البدائل والاستثناءات

| الرمز | الحالة | السلوك المطلوب |
|---|---|---|
| A1 | مرجع غير مخول أو بيانات لمؤسسة أخرى | رفض الطلب دون كشف المحتوى؛ يعاد التحقق عند طلب نسخة الطباعة أيضًا |
| A2 | تقييم جزئي أو فاشل أو بلا نتائج نهائية متاحة | عرض الحالة والمحتوى المحفوظ المتاح وحدوده؛ لا تنشأ نتائج نجاح افتراضية |
| A3 | نقص دليل أو تعذر استرجاع جزء من البيانات | بيان الجزء المتعذر وتأثيره. إذا تعذر إعداد تقرير مفهوم بمراجعه، يظهر الخطأ بدل الادعاء بإعداده كاملًا |
| A4 | خطة قديمة أو لم يثبت تطبيقها | عرض مرجع مدخلاتها وحدودها بوصفها اقتراحًا؛ لا يقدم أثرها المتوقع كإصلاح مثبت |
| A5 | اختلاف المتطلبات أو النطاق في المقارنة | إظهار الاختلاف وقابلية المقارنة لكل سؤال، دون تحويله تلقائيًا إلى تحسن أمني |
| A6 | تغير المحتوى الذي سيظهر في الطباعة عن المعاينة | طلب معاينة محدثة أو الحفاظ على المحتوى الذي عاينه المستخدم؛ لا يستبدل البيانات بصمت |
| A7 | إلغاء الطباعة أو تعذرها في المتصفح أو نظام التشغيل | يبقى التقرير قابلًا للعرض وفق الصلاحيات؛ لا تتغير بيانات المنصة ولا يُسجل نجاح طباعة غير مؤكد |

## ضوابط الإخراج

- الإخراج الأول المستهدف صفحة ويب قابلة للطباعة من المتصفح، مع عناوين واضحة وجداول مقروءة وفواصل صفحات مناسبة. لا تُعد هذه المواصفة تنفيذًا لتنسيق الطباعة بعد.
- تحفظ نسخة الطباعة تعريف النطاق والأزمنة ومراجع التقييمات والقيود حتى عند اختصار تفاصيل العرض. لا تستخدم مجموعًا يخفي الفحوص غير المحسومة أو غير المشمولة.
- وقت إعداد التقرير يختلف عن وقت جمع الدليل. القراءة التاريخية لا تثبت الوضع الحالي دون تقييم جديد.
- الإغلاق الإداري لا يثبت الإصلاح، ونجاح تشغيل المهمة لا يثبت استيفاء جميع المتطلبات، وخطة الإصلاح لا تثبت تنفيذها على GitHub.
- التقرير مخرج لنتائج محددة بأدلتها ونطاقها؛ لا يمنح بحد ذاته حكم امتثال شاملًا للمؤسسة.
